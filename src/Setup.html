1. Make a Spotify app (one time)

  1. Go to developer.spotify.com/dashboard, log in, and click Create app.
  2. Any name and description. Under Redirect URIs, paste this and click Add:
  3. Tick Web API, agree to the terms, and save.
  4. Open the app's Settings and copy the Client ID and Client secret into the boxes below.

2. Free Gemini API key (recommended)

Lets the script understand messy emails, for free. Go to aistudio.google.com/apikey, sign in with Google, click Create API key, and paste it here. No credit card needed. Without a key the script guesses one song per line or sentence and you fix more by hand.
Use Claude instead (paid, a few cents per run)
